# Agents Skill For You - Fits TextCove, I have my own AGENTS.md.. it's actually the same thing :)

Zero-dependency vanilla PWA: `index.html` + `app.css` + `app.js` + `boot.js` + `sw.js`. Node is dev-tooling only (no runtime deps, no bundler, no framework).

## Commands

- `npm run dev` → serves repo root at `http://localhost:6969` via `scripts/serve-local.mjs`. Must use HTTP, not `file://` (service worker and PWA install break on `file://`).
- `npm test` → `node --test tests/app.test.mjs tests/pwa.test.mjs tests/fixes.test.mjs`. Static source-assertion suites (read files, check strings); no browser/DOM runner.
- `npm run check` → `node --check` on `app.js`, `boot.js`, `sw.js`, `scripts/build.mjs`. Run after any JS edit.
- `npm run build` → `node scripts/build.mjs` hashes `index.html` + `404.html` + `changelog.html` + `app.css` + `app.js` + `boot.js` + `manifest.webmanifest` + icons + font, and rewrites `const cacheName = "textcove-<8hex>"` in `sw.js` in place. Run after touching any hashed file, before commit/deploy, or CI (`git diff --exit-code sw.js`) fails.

## Architecture / gotchas

- Storage: IndexedDB is primary, `localStorage` (`lsPutItem`/`lsGetItem`/`lsKeys`, `let useIdb` flag in `app.js`) is fallback + crash recovery. Don't remove fallback. Runtime caps live at the top of the app scope: `mirrorLimit`, `loadSafeLimit`, `maxFileSize`, `maxTextLen`, `maxImportNotes`, `trashMax`, `trashDays`, `backupDays`. `listCache` must be invalidated on every `idbPut`/`idbDel` via `invalidateListCache`, or the notes list goes stale.
- SW update flow is split across two files: `sw.js` handles `SKIP_WAITING`/`skipWaiting`/`clients.claim`/old-cache delete; `boot.js` registers `sw.js` with `updateViaCache: "none"`, polls via `reg.update()` (load/online/pageshow/15min interval), and reloads once on `controllerchange`. Keep both sides in sync. Tests assert `reg.update()` + `controllerchange` exist in `boot.js`, and no inline `<script>` remains in `index.html`.
- Native-only replacements are intentional: `a[download]`+`createObjectURL`/`revokeObjectURL` (no FileSaver), native `<dialog>` centered via `.app-dialog { margin: auto }` (no Smoke), hand-written `countText` (no Countable). Tests assert these stay absent.
- Markdown is escape-first: `escapeHtml` before `inlineMd` before `previewBody.innerHTML`. Code spans use `codes.push` + `@@tc` placeholders and must stay shielded from bold/italic/link. Link regex allows `https?` only. Supported: headings, bold, italic, strike `~~`, inline code, fenced code, `-` bullets, `1.` ordered lists, task lists, quotes, `---` hr.
- Names are hardening-sensitive: `sanitizeFileName` + `isReservedName` block path chars, control chars, `__proto__`/`constructor`/`prototype`; `touchMeta` skips reserved names. `title` renames on `change` only, never on `input`.
- Safety invariants asserted by tests - preserve them: note names via `textContent` never `innerHTML`; rename on title `change` event not `input`; never save placeholder text; editor settings set `content.style.fontSize` individually (never `content.style.cssText = settingValues`); delete moves straight to Trash via `moveNoteToTrash` and keeps `lastTrash` + `undoLastDelete` ("click here to undo") + `openFallbackNote`/`openNextAfterDelete`, Shift-click deletes permanently via `deleteNotePermanent` with confirm, concurrent deletes are blocked by `deleteRunning` and empty notes skip Trash but warn via `skipEmptyDeleteNotice` + the `dialogDontRemind` opt-out ("Don't remind me next time", persisted as `TextCove-skip-empty-delete-notice`) and are removed by `clearCurrentNote`; rename conflicts offer `generateNoteName` suggestion via `applyRename`; import caps `maxFileSize`/`maxImportNotes` + `sanitizeFileName`; no `execCommand`; no `navigator.share`/`shareNote`/`buildShareLink`; search is debounced 250ms via `searchTimer`, content search capped with `slice(0, 50000)`, list uses `listCache` + single-pass `idbGetAll`; oversized notes use `loadSafeLimit` + `handleOversizedNote` ("Download backup" then "Clear this note"); dialog keeps `lastFocus` + `restoreFocus` + Tab trap; menus sync via `syncMenuExpanded` + `MutationObserver`; boot reconciles via `reconcileRecovery` + `reserveName`; theme uses `currentThemeMode` with `"night"`/`"light"` only (never `"auto"` string) and follows OS when unstored; CSS keeps `IBM Plex Mono`, `.settings-menu`, `*::before`, `:active`, `dialog-in`, `--ease-out`, `#15181d`/`#1f242c`/`#e8eaf0`, no `.smoke-base`, no `rotate(`.
- PWA: `manifest.webmanifest` uses `start_url`/`id` `"./"`, maskable icon purpose `"any maskable"`, plus screenshots/categories/shortcuts. `sw.js` caches only `response.ok`, uses `Promise.allSettled` on install, keeps single `shellKey` for app shell, serves `./404.html` on 404 and guards non-HTML fallbacks with `event.request.destination`.
- Dev servers: canonical is `scripts/serve-local.mjs` (`Cache-Control: no-store`, SSE on `/__textcove_reload`). Root `serve-local.mjs` is legacy, untracked (see `.gitignore`), do not use or commit it. `index.html` must keep `src="boot.js"`, social tags (`og:title`, `twitter:card`, `rel="canonical"`), labels (`aria-label="Save note as text file"`, `for="fs"`, `<dialog>`, `aria-live="polite"`), `#logo`, `#icon-sun`/`#icon-moon`/`#themeIcon`, offline tip text, font preload and `aria-controls` on menus.
- Line endings: `.gitattributes` pins `eol=lf` and `scripts/build.mjs` strips `\r\n` before hashing, so the `sw.js` stamp is identical on Windows and CI. Never hash raw bytes without normalizing, or CI `git diff --exit-code sw.js` fails.
- Changelog: keep `CHANGELOG.md` and `changelog.html` in sync on every release entry; the info dialog links to `changelog.html`, never to the `.md`. `CHANGELOG.md` stays in git but is hidden on the live site via `.vercelignore` so `/CHANGELOG.md` 404s on Vercel while GitHub still shows it.
